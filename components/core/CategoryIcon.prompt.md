Two-tone category illustration for browsing/category-tile UI (auto, baby, electronics, pets, toys…) — not an inline text glyph like `Icon`. Use `reverse` on dark or True Blue backgrounds; it swaps to the art-directed dark colorway, not a mechanical color flip.

```jsx
<CategoryIcon name="electronics" size={48} />
<CategoryIcon name="pets" size={48} reverse />
```
