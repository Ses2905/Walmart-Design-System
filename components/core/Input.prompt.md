Rounded Walmart text input with True-Blue focus ring, optional label, leading icon, hint, and error state.

```jsx
<Input label="Email" type="email" iconLeft="mail" hint="We'll never share it" />
<Input label="ZIP code" error="Enter a valid ZIP" />
```

Props: `label`, `hint`, `error`, `iconLeft`, `size` `md|lg`, plus all native input props.
