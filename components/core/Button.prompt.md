Pill-shaped Walmart button — primary True Blue is the default CTA; `spark` flags a Sparky/AI-assist moment.

```jsx
<Button variant="primary" iconLeft="plus">Launch campaign</Button>
<Button variant="secondary">Save as draft</Button>
<Button variant="spark" size="lg">Ask Sparky</Button>
```

Variants: `primary` (True Blue), `secondary` (white + dark outline), `spark` (Everyday Blue), `ghost`, `ondark`. Sizes `sm | md | lg`. Supports `iconLeft`/`iconRight` (icon names), `block`, and all native button props.
