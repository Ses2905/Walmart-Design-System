Pill-shaped Walmart button — primary True Blue is the default CTA; `spark` (yellow) flags savings moments.

```jsx
<Button variant="primary" iconLeft="cart">Add to cart</Button>
<Button variant="secondary">Save for later</Button>
<Button variant="spark" size="lg">Shop deals</Button>
```

Variants: `primary` (True Blue), `secondary` (white + dark outline), `spark` (Everyday Blue), `ghost`, `ondark`. Sizes `sm | md | lg`. Supports `iconLeft`/`iconRight` (icon names), `block`, and all native button props.
