--measure-heading 20ch · text-wrap: balance

Headlines break into even lines, never one orphan word

--measure 62ch · text-wrap: pretty

Body copy runs to a fixed measure so the ragged edge stays shallow and every paragraph in a layout wraps at the same width. Sixty-two characters is the default column; use the narrow measure inside cards and the wide one for full-bleed editorial.

--measure-narrow 45ch — card copy

Short supporting copy inside a card or a sidebar, kept narrow enough to read in a glance.
