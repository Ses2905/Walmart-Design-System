# Advertiser + Agency Logo Library

Structure mirrors the internal-productivity packs.

- advertisers/parent-companies
- advertisers/brands
- advertisers/non-endemic
- agencies/holding-companies
- agencies/media-agencies
- agencies/commerce-specialists

Asset standard: SVG, 1:1 canvas, transparent background, lowercase hyphenated filenames.

This package is a structured starter library. Only source-verified logo artwork should be added as brand assets; no invented logos are included.
